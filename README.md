# BIT 2118: Scientific Computing

A comprehensive, production-grade repository implementing, verifying, and documenting **Tasks 2 through 20** for the **BIT 2118: Scientific Computing** curriculum.

Each task features:
1. **Original Implementation**: Complete Python implementation with all PDF OCR syntax errors corrected, headless Matplotlib figure generation (`matplotlib.use('Agg')`), and Section 2 parameter-modification sensitivity experiments.
2. **Modified Real-World Application**: A distinct, realistic engineering, environmental, biomedical, financial, or robotics application utilizing the exact same mathematical foundation and library routines.
3. **High-Resolution Figures**: Publication-quality charts saved to `outputs/` (`orig_task_XX.png` and `mod_task_XX.png`).
4. **Structured Markdown Documentation**: Full mathematical breakdowns (Sections B, C, D, E) located in `docs/Task_XX.md`.

## Installation & Environment Setup

1. **Clone the repository:**
   ```bash
   git clone <repository_url>
   cd "SCIENTIFIC COMPUTING"
   ```

2. **Create and activate a virtual environment (optional but recommended):**
   ```bash
   python -m venv .venv
   # On Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   # On Linux/macOS:
   source .venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
